04 / SERVICE STATUS

How LIVE is decided

Green LIVE is reserved for a successful, recent health check. Better-Api and MTXALLAPI must confirm that their database is connected. Messenger bots need an authenticated heartbeat from the running bot and connected platform. A stale result becomes UNKNOWN.

  • LIVE: recent verified check succeeded.
  • DEGRADED: the service answered but a required dependency is not ready.
  • OFFLINE: repeated health checks failed.
  • UNKNOWN: no recent verified result is available.

The Vercel monitor deployment, MongoDB connection settings, service health URLs, bot heartbeat integration, and alert delivery still need to be configured and verified. Existing API and bot deployments are not changed by this website monitor.

05 / HOSTING & UPTIME

Free tier, honest limits

The deployment target is free hosting. Free services may sleep, hit quotas, lose capacity, or become unavailable. The 24/7 goal is an effort, not a guarantee. The monitor records observed health; it does not keep a provider awake or promise an SLA.

See the repository README and monitor setup notes for the monitor's current setup requirements.
